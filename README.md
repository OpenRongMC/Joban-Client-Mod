# 常磐客户端模组（JCM）

简体中文 · [English](./README.en.md)


<p align="center"><img src="assets/JCM_logo.png" width="180" alt="JCM 标志"></p>

JCM 是 MTR 4 的车站设施扩展，为轨交场景增加更多可以使用和定制的设备。从紧急停车按钮、求助设施，到可自由定制的乘客资讯显示系统（PIDS），都可以用在站台、站厅和沿线设施中。

## RongMC 26.3 版本的改动

适配 MTR 26.3 平台层，更新资源生成和 PIDS 渲染路径。脚本工作线程会在客户端退出时清理。

## 安装

在 [GitHub Releases](https://github.com/OpenRongMC/Joban-Client-Mod/releases/tag/v2.0.0-port.1%2B26.3) 下载 **v2.0.0-port.1+26.3**。使用 Minecraft Java **26.3**、**Fabric** 和 **Java 25**。 依赖 [Fabric API](https://modrinth.com/mod/fabric-api)、[MTR](https://github.com/OpenRongMC/Minecraft-Transit-Railway)。 将发行 JAR 放进实例的 `mods/` 目录。 尽管名字含 Client Mod，它注册了世界方块，联机要在客户端和服务端都装。使用同系列的 MTR 与 JCM。
