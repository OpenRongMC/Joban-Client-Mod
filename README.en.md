# Joban Client Mod (JCM)

[简体中文](./README.md) · English

An MTR station-equipment addon with emergency stop buttons, helplines and customizable passenger information displays (PIDS). Scripts and resources drive some display content.

## Download and installation

- Version · [v2.0.0-port.1+26.3](https://github.com/OpenRongMC/Joban-Client-Mod/releases/tag/v2.0.0-port.1%2B26.3) (Release)
- Release asset · `rongmc-jcm-2.0.0-port.1.26.3.jar`
- Runtime · Minecraft Java 26.3, Fabric, Java 25
- Fabric Loader · `>=0.19.0`
- Fabric mod ID · `rongmc_jsblock`
- Dependencies declared by the JAR · [Fabric API](https://modrinth.com/mod/fabric-api), [`rongmc_mtr`](https://github.com/OpenRongMC/Minecraft-Transit-Railway) `4.0.5-port.1+26.3`

Place the release JAR in the instance’s `mods/` directory. Despite its name, JCM registers world blocks and belongs on both the client and server. Pair it with MTR from the same release family.

## How to try it

Place a PIDS in a station, choose a display configuration and confirm that passenger information updates. For custom display issues, include the display type and script or resource-pack version.

## Development

Develop and test alongside the matching MTR and platform mappings. The RongMC transport build uses Java 25. Use the coordinated workspace and release metadata when reproducing a release.
